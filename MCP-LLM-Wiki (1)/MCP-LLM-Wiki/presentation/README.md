# MCP 教學 HTML 簡報

- **主檔案**：`index.html`（單檔 HTML、CSS/JS 內嵌，不需要安裝額外套件；官方來源連結需網路）。
- **內容**：12 頁繁體中文入門教材。第 8 頁展示互動式七步 Tool Call，第 12 頁有三題測驗。
- **Windows 開啟方式**：在檔案總管找到 `presentation/index.html`，選「開啟方式 → Chrome / Edge」。可用下方按鈕或鍵盤左右箭頭換頁。
- **Wiki 對應**：每頁下方 S01–S05 連向官方資料；每頁顯示 `Wiki: xx` 對應頁名（非連結），可回到整個專案的 `wiki/xx.md` 查看；單獨發布 HTML 時，仍可點官方來源連結。
- **測試限制**：本次以 Chromium + Playwright 將 HTML 原始碼注入瀏覽器進行 DOM／互動及佈局檢查，桌面與手機尺寸均已測試；沙盒瀏覽器不允許直接開啟 file:// / localhost，仍需你在 Windows 直接開啟檔案確認。
- **分享連結**：若老師需要其他人可開啟的 URL，請部署到靜態網站（例如 GitHub Pages）；本機路徑不是可公開存取的 URL。
