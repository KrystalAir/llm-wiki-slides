# S01｜MCP 官方介紹

**[閱讀官方全文](https://modelcontextprotocol.io/docs/2026-07-28/getting-started/intro)**

## 關鍵摘記（中文轉述）

- MCP 提供 AI 應用與外部系統互通的開放標準；外部系統可能是檔案、資料庫、搜尋工具或專業工作流程。
- 標準化能降低應用整合不同服務的重複工序，但不保證所有服務都無需設定即可相容。
- 官方列出個人行事曆、企業資料庫、設計工具等場景，說明 MCP 的目的是讓 AI 能在受控情況下取得所需上下文與能力。
